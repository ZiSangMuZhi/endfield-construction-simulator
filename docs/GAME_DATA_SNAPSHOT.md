## 模式与配方切换规则

- 选中工业设备后，可先切换固体/液体模式，再在该模式下选择具体配方。
- 切换会清零当前加工周期，避免旧配方的部分进度完成为新产物；输入库存和产出库存保留。
- 模式切换会重新解析端口。与新模式不匹配的管道不会继续被视为有效连接，但蓝图线路本身不会被删除。
- 配方决定实际可接收/产出的物品、库存扣料、完成周期、线路图标和产销统计，不再由设备类型写死单一物品。

## 暂未启用的数据

公开资料还确认废水处理机能够低效率处理壤晶废液和惰性壤晶废液，但没有找到可交叉核验的当前周期，因此本版只启用污水 `1 / 2s` 的无返还物处理。扩容反应池、二型矿机与更多种植田块仍未进入本版本：扩容反应池需要“同一设备同时运行多个配方”，且占地、功率、独立配方槽数和逐格端口尚未形成一致证据；其他设备仍有区域限制或关键数据缺口。塑形机的液体模式名称可以确认，但没有找到足以核验的独立液体配方，因此没有伪造模式选项。拆解机、提纯机、废水处理机和本轮新增物品虽已进入数据与模拟，但正确缩略图尚未随项目分发，界面使用明确的“待补图”内容占位符，等待后续素材替换。论坛与攻略的证据分级、矛盾项和暂缓决定见 `COMMUNITY_RESEARCH.md`。
