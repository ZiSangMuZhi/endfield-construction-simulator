这是《明日方舟：终末地》工业规划模拟器的首个公开预览版。

在线使用：[GitHub Pages](https://zisangmuzhi.github.io/endfield-construction-simulator/)

## 版本重点

- 在默认 32×32 画布上规划设备、传送带与管道，支持缩放、平移、框选、复制、旋转、移动和拆除。
- 传送带与管道使用独立占位层，支持自动寻路、端口吸附、正交桥接、物流部件、在途货物和完整背压。
- 设备会根据库存自动匹配配方，并模拟供电、投入/产出库存、处理周期、阻塞和上下游吞吐。
- 提供产销统计、设备状态列表和忽略逐格线路形状的流程图视图。
- 收录 22 种生产设备与 147 条配方；传送带带宽为 30/min，当前管道模型为 120/min。
- 完成浅色游戏蓝图视觉体系，并统一重绘传送带、管道与框选编辑工具图标。

## 常用操作

- `E`：传送带模式
- `Q`：管道模式
- `X`：框选模式
- `R` / `M` / `C`：旋转 / 移动 / 复制选中对象
- `Delete` 或 `Backspace`：拆除选中对象
- 鼠标滚轮：缩放；按住滚轮拖动：平移

## 说明

本版本仍为 Alpha。部分设备的逐格端口位置、社区实测吞吐和缺失游戏图片会在后续版本继续核实、补全。数据来源与素材许可登记见仓库内 `docs/DATA_AND_ASSETS.md` 和 `docs/THIRD_PARTY_ASSETS.md`。
