# 产品规格（Alpha → 1.0）

## 用户任务

玩家在游戏外快速复刻或设计基地，验证物流连通性，预测每分钟产出，并明确看到哪些设备没有满速以及原因。

## Alpha 验收

- 能连续放置、覆盖与删除传送带/管道/设备。
- 传送带和管道按拖拽顺序记录入口/出口；只有“上游出口 → 下游入口”握手成功才连通，几何相邻不得误连。
- 连续线路自动形成直线和圆角弯头；模拟时箭头和物品图标沿整条有向路径连续移动，跨格转交不重置动画。
- 生产设备在占地边缘明确显示输入/输出端口；端口方向与旋转后的设备方向一致。
- 已核实的设备严格按真实地面占格放置，并阻止重叠。
- 黑白主题下关键信息对比度清晰。
- 画布可调整网格行列、网格对比度和缩放比例，并可平移查看大布局。
- 默认视觉严格遵循游戏蓝图预览的浅灰工程图语言：宽幅黄色传送带、粗灰管道、圆角转向、重复方向箭头和黑白设备轮廓；动画不得依赖发光或装饰性阴影。
- 编辑快捷键采用游戏习惯：`E` 选择传送带，`Q` 选择管道。
- 新建管道可选择清水、液化息壤或污水，管体颜色随内容数据变化。
- 开始模拟后同时显示正常运转与等待设备。
- 蓝图刷新页面后可通过本机存档恢复。

## 1.0 验收

- 计算结果可由小型手算案例复核。
- 每个低利用率设备给出可追溯原因：缺哪项输入、上游哪台设备不足、或下游何处堵塞。
- 游戏数据带版本号且可迁移旧蓝图。
- 支持 JSON 导入导出，损坏文件不会覆盖当前蓝图。

## 非目标

首阶段不做账号系统、云端协作、社区蓝图库或自动抓取游戏数据。
