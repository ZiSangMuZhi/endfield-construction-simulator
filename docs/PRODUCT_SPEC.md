# 产品规格（Alpha → 1.0）

## 用户任务

玩家在游戏外快速复刻或设计基地，验证物流连通性，预测每分钟产出，并明确看到哪些设备没有满速以及原因。

## Alpha 验收

- 当前阶段只开放传送带、仓库取货口、固体加工设备与供电桩；管道和储液罐暂缓，避免流体逻辑干扰固体生产链验收。
- `E` 进入传送带构建模式，首次单击创建起点，后续每次单击增加一个路径点；非相邻路径点通过 A* 自动绕开所有设备和既有线路。悬停/单击设备时，起点吸附可用输出口，后续终点吸附可用输入口；`E` 或 `Esc` 完成，右键取消当前草稿。
- 传送带按路径点顺序记录入口/出口；只有“设备输出口 → 完整有向线路 → 设备输入口”握手成功才连通，几何相邻、悬空终点或反向格不得误连。
- 连续线路使用单条无接缝描边形成直线和圆角弯头，不显示格点节点；箭头保持静态指向，物品图标沿整条有向路径连续移动，跨格转交不重置动画。
- 弯道格的方向箭头沿进入与离开方向的角平分线显示为 45°；鼠标悬停格子不得出现方形描边。
- 生产设备只绘制一个完整占地外轮廓，内部占格不得生成额外方框；端口由设备目录中的输入/输出数组逐一渲染，旋转设备后同步换边，后续设备可声明不同端口数量。
- 已核实的设备严格按真实地面占格放置，并阻止重叠。
- 仓库取货口按 `1×3` 占地，旋转后为 `3×1`，输出端口位于朝向侧的中间格。
- 选中仓库取货口后可为该实体单独选择矿物或工业产物；选择结果随蓝图保存和复制，线路使用所选物品图标。未选择物品的取货口不得输出。
- 黑白主题下关键信息对比度清晰。
- 画布可调整网格行列、网格对比度和缩放比例，并可平移查看大布局。
- 默认视觉严格遵循游戏蓝图预览的浅灰工程图语言：宽幅黄色传送带、粗灰管道、圆角转向、重复方向箭头和黑白设备轮廓；动画不得依赖发光或装饰性阴影。
- 编辑快捷键采用游戏习惯：`E` 选择传送带；`Q` 在流体阶段开放前仅提示功能暂缓。
- 长按设备进入拿起/移动；`X` 选择方块后可用 `C` 复制、`R` 旋转、`M` 移动、`Esc` 取消，旋转设备时端口同步换边。
- 供电桩占地 `2×2`，规划供电范围为以设备为中心的 `12×12` 方形区域；工业设备没有与任一范围相交时显示“未供电”并停止进度。
- 选择供电桩或供电桩工具时显示低对比度蓝色供电范围框及“规划参考”标签，未选择时保持蓝图画面简洁；显示框和模拟判定必须共用同一范围数据。
- 工业设备本体明确显示设备名称、当前配方、工作状态、供电状态、阻塞状态、进度和剩余时间。
- 悬停或键盘聚焦传送带时显示当前物品图标、当前流速与额定 `30/min` 带宽。
- 界面不使用 Emoji；优先使用登记过的游戏设备图标，其次使用 CSS/文字图形，再无可用图标时生成与蓝图风格一致的项目素材。
- 开始模拟后同时显示正常运转与等待设备；仅完整连接、源端存在物品且源设备可输出的线路生成运输图标，悬空线路始终为零流量。
- 工业设备显示当前周期进度条、完成百分比和剩余时间；线路按当前运输格数量同时显示物品图标。
- 每台工业设备按自身实体 ID、输入端口和输出端口独立计算状态；无输入显示缺料、无输出显示阻塞，复制设备不得继承源设备进度。
- 普通传送带额定带宽为 `30/min`。
- 蓝图刷新页面后可通过本机存档恢复。

## 1.0 验收

- 计算结果可由小型手算案例复核。
- 每个低利用率设备给出可追溯原因：缺哪项输入、上游哪台设备不足、或下游何处堵塞。
- 游戏数据带版本号且可迁移旧蓝图。
- 支持 JSON 导入导出，损坏文件不会覆盖当前蓝图。

## 非目标

首阶段不做账号系统、云端协作、社区蓝图库或自动抓取游戏数据。
