# 产品规格（Alpha → 1.0）

## 用户任务

玩家在游戏外快速复刻或设计基地，验证物流连通性，预测每分钟产出，并明确看到哪些设备没有满速以及原因。

## Alpha 验收

- 当前阶段开放传送带、管道、仓库端口、首批固体/流体加工设备、物流部件与供电桩；储液罐仍等待独立缓存规则核实。
- `E` 进入传送带构建模式，首次单击创建起点，后续每次单击增加一个路径点；非相邻路径点通过 A* 自动绕开设备。点击成功连接的输入口立即完成建造。新线路不得覆盖既有同层线路：两条直线正交时自动把交叉格替换为物流桥/管道桥，其他占位冲突必须红色预览并拒绝提交；若末端按入口方向落在无既有上游的同类线路起点，可接续其下游。也可单击既有线路中任一格作为改线锚点；`E` 或 `Esc` 完成，右键取消当前草稿。
- 起点建立后，鼠标移动到新格时必须从最后一个已确认路径点实时计算避障路径并显示临时预览；临时段不写入蓝图，单击才把当前预览固化为路径点，悬停设备时预览终点同步吸附可用端口。
- 传送带按路径点顺序记录入口/出口；“设备输出口 → 完整有向线路”握手成功后即可接收物品，目标输入口只决定末端能否卸货。几何相邻、悬空起点或反向格不得误连；悬空末端允许积货但不能凭空消耗物品。
- 连续线路使用单条无接缝描边形成直线和圆角弯头，不显示格点节点；箭头保持静态指向，物品图标沿整条有向路径连续移动，跨格转交不重置动画。
- 弯道格的方向箭头沿进入与离开方向的角平分线显示为 45°；鼠标悬停格子不得出现方形描边。
- 生产设备只绘制一个完整占地外轮廓，内部占格不得生成额外方框；端口由设备目录中的输入/输出数组逐一渲染，旋转设备后同步换边，后续设备可声明不同端口数量。
- 已核实的设备严格按真实地面占格放置，并阻止重叠。
- 单击直接选择单个对象；`X` 只作为框选模式开关。框选区域会纳入完整设备实体以及区域内的传送带、管道和物流部件，支持整组复制、顺时针旋转、吸附移动与删除，并保持对象相对位置和双物流层关系。
- 仓库取货口按 `1×3` 占地，旋转后为 `3×1`，输出端口位于朝向侧的中间格。
- 选中仓库取货口后可为该实体单独选择矿物或工业产物；选择结果随蓝图保存和复制，线路使用所选物品图标。未选择物品的取货口不得输出。
- 界面只保留游戏蓝图预览对应的浅色主题，不提供深色模式；关键信息保持清晰对比。
- 画布可调整网格行列、网格对比度和缩放比例，并可平移查看大布局；画布外围为纯色背景，不重复绘制第二层网格。
- 默认视觉严格遵循游戏蓝图预览的浅灰工程图语言：宽幅黄色传送带、透明空管、浅色流体填充、圆角转向、重复方向箭头和黑白设备轮廓；动画不得依赖发光或装饰性阴影。
- 编辑快捷键采用游戏习惯：`E` 选择传送带，`Q` 选择管道；两种线路共用路径点、实时寻路、中段改线和端口吸附手势。
- 管道与传送带使用独立占位层，普通管道允许直接跨过传送带；同类型正交跨越分别使用管道桥与物流桥，两个方向不得交换内容。
- 分流器、汇流器、物流桥及对应管道部件可以把朝向匹配的输入/输出口直接贴合设备端口，不要求中间再留一格线路。直连必须参与正常吞吐、库存转交和背压；同一边界只显示一个端口图标，设备与物流部件直连时优先显示设备端口。
- 物流桥与管道桥没有库存：从任一输入侧进入的货物或液体只能交接到正对面的配对输出，绝不能转向相邻边。两条正交轴线独立运行；正对出口缺失或堵塞时，货物停在桥前并向上游形成背压。
- 单击设备或传送带即可选中；整条传送带与设备均可用 `C` 复制、`R` 旋转、`M` 移动、`Esc` 取消。移动对象随指针移动并显示网格吸附框，非法目标明确标红且不会移除源对象。
- 主按钮在设备上保持 420ms 后打开四向轮盘；打开前移动超过 14px 取消长按，打开后中央 30px 为取消区。上、右、下、左分别映射旋转、移动、复制、拆除；指针越区实时高亮，松开后高亮闪烁 210ms 再执行，`Esc` 和指针取消事件不得误提交。
- 选中后可用工具条“拆除”或 `Delete` / `Backspace` 删除；设备必须删除完整占地和独立库存，传送带必须删除整条连续线路。
- 无需修饰键的鼠标滚轮缩放画布，按住鼠标中键拖动画布。
- 构建栏把“传送带、选择”等编辑工具与可放置设备分开；设备按游戏目录提供“全部、资源开采、仓储存取、基础生产、合成制造、电力供应、功能设备、战斗辅助、种植调配”筛选。
- 供电桩占地 `2×2`，规划供电范围为以设备为中心的 `12×12` 方形区域；工业设备没有与任一范围相交时显示“未供电”并停止进度。
- 选择供电桩或供电桩工具时显示低对比度蓝色供电范围框及“规划参考”标签，未选择时保持蓝图画面简洁；显示框和模拟判定必须共用同一范围数据。
- 工业设备本体明确显示设备名称、当前配方、工作状态、供电状态、阻塞状态、进度和剩余时间。
- 选中多配方设备后显示工作模式与配方控件；空闲且尚未开始一个加工周期时，根据输入库存中已具备的物品自动选择匹配度最高、可立即开工优先的配方。手动切换配方或模式会清零当前周期、保留库存，并立即更新设备端口、线路物品、配方文本和产销统计。
- 当前目录至少包含 16 种可模拟生产设备和 56 条可追溯配方；装备原件机覆盖紫晶、蓝铁、高晶、息壤、赤铜和赫铜六种装备原件，全部使用 10 秒周期与整数批量投料；粉碎机和研磨机包含砂叶粉末链，采种机只使用固体输入并支持锦草、芽针；拆解机与提纯机必须使用其真实名称、占地、功率和双介质/双输出规则，废水处理机以 `3×3`、50 功率和 `30/min` 污水无返还处理建模。尚未提供正确图片的设备与物品显示具名“待补图”内容占位，不生成图片、不冒用相近素材，也不影响拖放、库存或模拟。
- 设备详情根据单次配方数量与周期实时显示额定输入/产出流量；该值是理论上限，不替代传送带吞吐、供电、库存和缺料共同决定的实际产销统计。
- 悬停或键盘聚焦传送带时显示当前物品图标、当前流速与额定 `30/min` 带宽。
- 界面不使用 Emoji；优先使用登记过的游戏设备图标，缺图时统一使用 CSS/文字内容占位符，并保留稳定数据 ID 供后续直接替换。
- 开始模拟后同时显示正常运转与等待设备；只要线路连接有效输出口、源端存在物品且首格可接收，设备就会发货。未接输入口的末端保留物品并逐格堆积；未接输出口的线路始终为零流量。
- 右侧分析面板直接紧凑列出当前产线涉及的全部物品，不使用单项选择器；每个物品的产出和消耗使用同一张最近 5 分钟迷你折线图，按 5 秒取样并使用 30 秒滚动平均。机器完成配方与仓库取货口实际发货计入产出，只有配方扣料计入消耗，进入仓库存货口的货物只算库存转移。
- “重置模拟”停止运行并清零时钟、设备库存/进度、在途物流、线路吞吐和产销历史，但不得改变蓝图布局、设备配方或仓库取货口物品配置。
- “清空画布”必须二次确认；确认后停止模拟并清除主网格、管道层、选择/草稿和全部模拟状态，但保留浏览器中已保存的蓝图，允许用户重新载入。
- 工业设备显示当前周期进度条、完成百分比和剩余时间；线路只显示仿真中真实存在的全部在途物品。
- 生产进度条在相邻固定模拟步之间平滑线性推进，新周期归零时直接复位；平滑显示不得改变配方耗时、产出时刻或后台固定步长。
- 所有设备端口必须绘制在独立于设备占格的全局顶层；任何后放置或高层级设备都不得遮住其他设备的固体/液体输入输出口，直连边界仍只显示一个端口。
- 画布工具栏提供“蓝图 / 流程图”切换。流程图以类似节点编辑器的缩略节点和曲线显示工业设备连接，不绘制逐格传送带或管道形状；物流桥和管道桥折叠为透明中继，分流器、汇流器及其管道版本必须保留为可见节点。
- 每台工业设备按自身实体 ID、库存和配方独立计算状态；无输入显示缺料、产出库存满显示阻塞，复制设备不得继承源设备库存或进度。
- 选中设备后显示专用库存菜单，固体输入与液体输入分别按 `50` 单位计容并独立触发背压；产出库存、当前配方和测试用直接投料仍单独显示。
- 下游设备输入库存满时，设备完整外框标红，连接线路停止发货，已到末端的物品保持可见并等待容量释放。
- 同一设备的多条有效输出线路共享轮询游标：单件产出依次轮流选择线路；产出缓存足够时，各线路可在同一带宽周期同时出货。
- 同一配方有多个同介质产物时，输出口可以显式绑定配方输出下标；提纯机上方管口发送副产物、下方管口发送主产物，线路悬浮信息、库存扣取和发货必须使用同一映射。
- 蓝铁块冶炼周期为 `2s`，进度归零、产出写入与输出口发货必须由同一个完成事件驱动。
- 普通传送带额定带宽为 `30/min`。
- 每个传送带格最多容纳 1 件物品。相邻货物可以连续占据相邻格，不要求额外空格；末端不能卸货时，最前物品停在末端半格，后续物品逐格排满。只有线路首格重新腾空时源设备才能继续发货，整线占满即形成背压。
- 传送带额定 `30/min` 与画面位置完全解耦；相邻货物的视觉排列不得再形成第二个发货节流器。管道使用独立的 `120/min` 物流参数，水泵以 `60/min` 生成清水。
- 吞吐与旅行时间必须是两个独立时序概念：每条线路每 2 秒最多发 1 件；转弯不重置位移，阻塞会延长实际交付时间但不会让物品重叠或越过前车。
- 传送带直接投影全部在途货物；管道不绘制单位液体图标，而按每格液体占用率改变浅色内填充粗细。两者都只在成功写入目标库存后删除模拟中的在途单位。
- 模拟内核每 250ms 提交一次库存、配方和逐格位置快照；每条线路只使用一个 `requestAnimationFrame` 循环批量插值该线路全部图标，画布网格不得跟随显示帧率高频重建。
- 底部设备目录只支持拖放添加，不提供“单击目录再单击画布”的放置路径；拖入画布时显示按真实占地计算的吸附框，松开只在完整占地合法时提交。
- 精炼炉和配件机当前配方周期均为 `2s/个`；进度、扣料、产出写入和输出发货使用相同模拟时钟。
- 右侧设备状态卡与底部设备目录使用同一设备图片来源和同类缩略图边框，不以文字缩写代替已有设备图标。
- 设备状态列表将 `blocked` 设备稳定排序到顶部；非阻塞设备保持原相对顺序，设备编号不随临时排序变化。
- 蓝图刷新页面后可通过本机存档恢复。

## 1.0 验收

- 计算结果可由小型手算案例复核。
- 每个低利用率设备给出可追溯原因：缺哪项输入、上游哪台设备不足、或下游何处堵塞。
- 游戏数据带版本号且可迁移旧蓝图。
- 支持 JSON 导入导出，损坏文件不会覆盖当前蓝图。

## 非目标

首阶段不做账号系统、云端协作、社区蓝图库或自动抓取游戏数据。
