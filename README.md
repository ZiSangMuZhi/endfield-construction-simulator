# 终末地 · 工业规划台

一个轻量、离线优先的《明日方舟：终末地》基地布局与生产模拟工具。当前版本是可操作的 Alpha 原型。

## 已实现

- 18 × 12 网格规划画布
- 传送带与管道采用独立占位层：管道可从传送带上方通过；物流桥、管道桥、分流/汇流器和管道分流/汇流器均可放置并参与物流转交
- 已加入精炼炉、粉碎机、配件机、塑形机、采种机、种植机、灌装机、封装机、研磨机、反应池、天有洪炉、装备原件机、水泵、仓库端口与 2×2 供电桩
- 工业设备使用数据驱动的多配方模型；精炼炉、灌装机和种植机可在已核实的固体/液体模式间切换，模式会同步改变可用管道端口、配方、周期和线路物品
- `E` 进入传送带模式、`Q` 进入管道模式：首次单击设起点，后续单击增加路径点，A* 自动绕开设备；新线路覆盖同层重叠格，末端落在既有线路上时继承其下游方向；也可从既有线路中段重新规划
- 低对比度蓝色 12×12 规划供电范围框、设备供电/缺料/阻塞/等待状态，以及按物品查看的产出/消耗双折线
- 设备单一完整外框、数据驱动的多输入/输出端口、名称/配方/进度/剩余时间
- 单击即可选中设备或整条传送带；复制、旋转、移动、拆除均按完整对象提交，移动时对象随指针移动并显示网格吸附/冲突框；`Delete` / `Backspace` 或工具条按钮可拆除
- 在设备上按住 420ms 可呼出方向轮盘：上旋转、右移动、下复制、左拆除；拖出中央取消区后松开确认，选项短促闪烁后执行
- 工具与设备目录分离；设备目录采用游戏内“全部、资源开采、仓储存取、基础生产、合成制造、电力供应、功能设备、战斗辅助、种植调配”分类
- 设备只允许从底部目录拖到画布，避免点选工具后误触重复放置；拖放期间显示完整占地吸附框与冲突状态
- 无修饰键滚轮缩放、中键拖动画布；网格尺寸和对比度可调
- 传送带构建时从最后一个已确认路径点到鼠标格实时运行避障寻路并预览；点击只负责固化路径点
- 传送带只要接入设备输出口即可收货；每格最多容纳 1 件，悬空末端或下游满载时会从末端逐格堆积，整线占满后反压源设备。每件货物从真实输出口边界进入线路，并在存在输入口时完成交付
- 传送带吞吐与画面间距解耦：额定速率固定为 `30/min`，阻塞时货物可无空格连续占满线路，不会因显示间距再次降速
- 管道当前按 `120/min` 单管吞吐、每格 4 个流体单位建模；水泵按 `60/min` 产出清水。空管透明，液体种类决定浅色填充，逐格液量决定填充粗细，不再绘制单位液体图标
- 模拟状态每 250ms 原子提交一次，货物图标在两次快照之间用独立逐帧插值平滑移动，避免高频重绘整个网格
- 每台设备拥有独立输入/产出库存和处理进度；固体与液体输入分别拥有 `50` 单位容量，专用库存面板支持测试用直接投料，复制设备从空库存、零进度开始
- 下游库存满或线路没有输入端时，货物占满每个传送带格后停止发货；源设备产出缓存继续累积，缓存满后进入阻塞
- 同一设备连接多条输出线路时，单件产出按线路轮询；缓存足够时所有可用线路按各自 30/min 带宽同时发货
- 仓库取货口可独立选择矿物或工业产物；物品选择会同步影响线路图标、产出统计与配方输入判定。仓库存货口收货只算库存转移，不算消耗
- 产销历史按真实配方完成、配方扣料和仓库取货口发货事件记录；右侧紧凑列出产线涉及的全部物品，每项在同一迷你图中对比最近 5 分钟的产出/消耗，并用 30 秒平滑窗口抑制短周期震荡
- 已登记设备与物品优先统一使用参考项目收录的游戏 WebP 素材；装备原件机、塑形机、灌装机、反应池、仓库端口及主要工业物品不再使用项目占位 SVG
- “重置模拟”会停止时钟并清空库存、进度、在途货物、吞吐与产销历史，同时保留蓝图布局、配方和仓库取货配置
- 单一浅色蓝图主题，本机保存/载入蓝图
- 桌面与窄屏布局

## 本地运行

需要 Node.js 22.13+。执行 `npm install` 后运行 `npm run dev`。

## 数据声明

Alpha 版已录入一批可追溯数据：传送带 `30/min`、13 种生产设备、固体/液体工作模式、28 条配方、配方整数投入/产出与 `1s` / `2s` / `10s` 周期、水泵与管道实测吞吐、相关设备占地和端口兼容配置。未公开的逐格端口细分仍明确标为暂定；数据快照见 `docs/GAME_DATA_SNAPSHOT.md`，字段来源和素材登记见 `docs/DATA_AND_ASSETS.md`。

## 路线图

1. 基础布局：旋转、框选、撤销/重做、碰撞与设备占地。
2. 物流图：端口连接、分流/合流、带速、管网与缓存。
3. 离散事件模拟：配方周期、库存、阻塞、缺料、功率与时钟等待。
4. 分析：理论/实际产出、瓶颈定位、未满速原因链。
5. 数据与分享：版本化游戏数据、蓝图导入导出、分享链接。
