# 终末地 · 工业规划台

一个轻量、离线优先的《明日方舟：终末地》基地布局与生产模拟工具。当前版本是可操作的 Alpha 原型。

## 已实现

- 18 × 12 网格规划画布
- 传送带、管道、仓储接口、精炼/装配设备、储液罐放置
- 按住拖拽连续铺设，右键拆除
- 演示模拟时钟、设备全速/等待状态、流量面板
- 黑白双主题，本机保存/载入蓝图
- 桌面与窄屏布局

## 本地运行

需要 Node.js 22.13+。执行 `npm install` 后运行 `npm run dev`。

## 数据声明

Alpha 版中的产能、功率和配方均为用于验证模拟流程的演示数据，不代表游戏正式数值。正式数据接入策略见 `docs/DATA_AND_ASSETS.md`。

## 路线图

1. 基础布局：旋转、框选、撤销/重做、碰撞与设备占地。
2. 物流图：端口连接、分流/合流、带速、管网与缓存。
3. 离散事件模拟：配方周期、库存、阻塞、缺料、功率与时钟等待。
4. 分析：理论/实际产出、瓶颈定位、未满速原因链。
5. 数据与分享：版本化游戏数据、蓝图导入导出、分享链接。
